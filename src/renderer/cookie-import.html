Как создать файл с cookies?

Способ 1 — Cookie-Editor (самый простой):

  1. Установите расширение Cookie-Editor в Chrome / Edge / Brave (или Opera GX).
  2. Войдите в Avito под нужным аккаунтом.
  3. Откройте Cookie-Editor → внизу кнопка Export → Export as JSON.
  4. Сохраните файл, например avito-account1.json.
  5. Здесь: «Выбрать файл» → укажите его.

Способ 2 — Netscape (curl / wget / yt-dlp):

  1. Плагин «Get cookies.txt LOCALLY» или yt-dlp --cookies-from-browser chrome --cookies cookies.txt.
  2. Формат строки: domain ⇥ flag ⇥ path ⇥ secure ⇥ expiry ⇥ name ⇥ value (таб-разделённые).
  3. Brouser понимает оба формата — JSON и Netscape.

Что важно:

  • Cookies должны быть с домена .avito.ru (и поддоменов, если есть).
  • Пароли и логины не нужны — только cookies.
  • Файл содержит чувствительные данные (по сути ключ от сессии): не передавайте третьим лицам, не коммитьте в git, храните локально.
  • После импорта проверьте: откройте avito.ru в этом профиле — вы должны быть залогинены без ввода пароля.
  • Если Avito разлогинивает сразу — cookies истекли, либо IP-адрес прокси не совпадает с тем, с которого они получены: cookie привязан к IP-сессии, импорт с другого IP не работает.

Безопасность: Brouser хранит cookies в userData/Partitions/<profile>/Cookies в зашифрованном виде (шифрование Chromium). Импортированный файл после загрузки можно удалить.
