# Roadmap

Фазы с критериями выхода. Детали задач — в BACKLOG.md.

## v0.2 — «Brouser запускается» (текущая цель)
Критерий: `npm run dev` открывает окно, сетка из 2 профилей Avito, resize
работает без дрожания, оба профиля грузят avito.ru.
Задачи: P1.1, P1.2, P1.3 + P2.5 (краш удаления профиля) — **готово**
(layout.ts, handshake, parking, безопасный teardown); ручная проверка на
целевой машине — см. чек-лист в конце.

## v0.3 — «Не банят»
Критерий: browserleaks.com/canvas и /webgl дают **разные** отпечатки для
avito1 и avito2; browserleaks.com/javascript — одинаковый UA+timezone+CH,
разные hardwareConcurrency/GPU.
Задачи: P0.1, P0.2, P2.4. — **антидетект-механика готова** (двойная
инъекция, Client Hints, логирование); языки/геолокация/экран/медиа-устройства/
шрифты per-profile (P3) — тоже готовы (см. BACKLOG, коммит
`feat(antidetect-surfaces)`); проверка на целевой машине — чек-лист.

## v0.4 — «Упаковано»
Критерий: `npm run dist:win` собирает установщик, установленный Brouser
подхватывает `config.json` из userData и расширения из `extensions/` рядом
с exe (extraResources).
Задачи: P2.2 (macOS часть — опционально), ревизия electron-builder.yml
(проверить попадание `dist/main/fingerprint-preload.js` в пакет —
copy-assets.js уже включён в `npm run build`).

## v1.0 — «Рабочий инструмент»
Критерий: 5 профилей Avito работают 7 дней без банов на резидентских прокси.
Задачи: P2.1, P2.3, полировка журнала — **готово**; остаются полевые
испытания и итерации по факту банов (антифрод Avito обновляется — закладывать
отдельный релизный цикл на фингерпринт-модуль, см. P3-BACKLOG).

## v1.1 — «Умный FAQ» (текстовый ассистент)
Критерий: 8 тест-кейсов текстового чата проходят на реальном Electron —
список профилей, хвост логов, FAQ по документации (RAG со ссылкой на
раздел), смена раскладки, отказ на удаление профиля, отказ + предупреждение
на запрос пароля, offline-сообщение, те же результаты на local-fallback.
Ни один тул не даёт доступа к паролям, cookies, произвольным файлам и JS;
регрессия сетки/профилей/антидетекта — нулевая; docs/assistant-tools.md
создан. Этапы — P4 в BACKLOG.md (этапы 0–4), коммиты
`feat(assistant): stage N — …`.

## v1.2 — «Jarvis» (голос)
Критерий: цикл wake word → VAD → STT → LLM → TTS работает end-to-end на
Windows (проверено пользователем); ≤ 3 с от конца речи до начала ответа;
голос включается только тумблером (по умолчанию выключен); аудио не пишется
на диск и не отправляется до срабатывания wake word (кроме явного
debug-режима); docs/assistant-voice.md создан. Этапы — P4 в BACKLOG.md
(этапы 5–6).

## Чек-лист проверки после модернизации (прогнать на целевой машине)

1. `npm run build` — 0 ошибок typecheck. (выполнено в песочнице: OK)
2. `npm run dev` — окно открылось, 2 профиля загрузили avito.ru.
3. Resize окна 10 раз туда-обратно — views не дрожат.
4. Смена раскладки 2x2 -> 1x1 -> 2x2 — views не теряют состояние
   (проверить по залогиненности).
5. browserleaks.com/canvas в avito1 и avito2 — разные хеши.
6. Перезагрузка avito1 — тот же хеш (консистентность).
7. browserleaks.com/javascript в avito1 и avito2 — одинаковый UA, разные
   hardwareConcurrency (если разные seed).
8. DevTools в ячейке avito1 — не падает, таймзона и патч сохраняются
   (в app.log: «CDP-отладчик временно отключён» / «восстанавливаю CDP-эмуляцию»).
9. В app.log есть строки `fingerprint: seed=…, canvas=patched, webgl=…, ch=…`.
10. Удаление профиля: 1 из 2 (второй остаётся залогинен) и единственного
    (сетка пустеет, счётчик 0/N) — без нативного краша (crashpad), без
    «target closed while handling command» в app.log.
11. Удаление профиля при открытом DevTools этой ячейки — не падает;
    в app.log нет попытки восстановить CDP-эмуляцию на мёртвом таргете.
12. Сетка пустая -> «Добавить» -> новый профиль грузит URL в первую ячейку;
    то же самое после запуска с `profiles: []` в config.json.
13. `userData/fingerprint-preloads/` не содержит файла удалённого профиля.
14. `browserleaks.com/javascript` в avito1/avito2: `navigator.languages`
    соответствует региону таймзоны (ru-RU для Europe/Moscow);
    `screen.width/height`/`devicePixelRatio`/`enumerateDevices` — разные
    при разных seed; в app.log — `locale=…, geo=…, screen=…, mdev=…`.
15. Гео-тест в ячейке: координаты в регионе таймзоны БЕЗ запроса разрешения;
    `permissions.query({name:'geolocation'})` -> `granted`;
    header `Accept-Language` совпадает с `navigator.languages[0]`.
16. `sec-ch-ua` в сниффере запросов побайтово совпадает с реальным Chrome
    той же мажорной версии (напр. Chrome/131 ->
    `"Google Chrome";v="131", "Chromium";v="131", "Not_A Brand";v="24"`).

Пункты 2–12 требуют GUI и живой сети — в headless-песочнице не проверяемы;
механика, не требующая GUI, проверена unit-тестами в песочнице
(fingerprint-патч в мок-DOM, layout-математика, parseProxy), код —
`tsc --noEmit` без ошибок.
